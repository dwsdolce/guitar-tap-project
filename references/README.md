# References

Third-party reference material — papers and visualizations that informed Guitar Tap's DSP
and UI (pitch detection, resonance analysis, spectrum display) across all three editions.
Kept here as shared project reference rather than in any one edition's repo. Not authored
by the project; retained for provenance.

- **`2002_JASA_YIN.pdf`** — de Cheveigné & Kawahara, *YIN, a fundamental frequency estimator for speech and music* (JASA, 2002).
- **`Comparing Pitch Detection Algorithms vs Neural Network.pdf`** — survey comparing conventional pitch-detection algorithms with a neural-network approach.
- **`Fast and Efficient Pitch Detection - Cycfi Research.webloc`** — bookmark to the Cycfi Research article.
- **`Spectra.png`** — a downloaded FFT-spectra comparison (two annotated tap-tone captures); kept as a spectrum-display / annotation-style reference.

Moved here from `guitar_tap/docs/` during the post-standup cleanup (2026-08-03).
