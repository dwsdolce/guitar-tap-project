reference** for both algorithm and UX) and **guitar_tap** (Python, the mirror). The
three repos keep separate, idiomatic source trees. This map is the source of truth for
**where the corresponding code lives**; the shared numeric contract is the **oracle**
(`tooling/parity/parity-oracle.json` — see `TEST-COVERAGE.md` for its current status).

tags and run `tooling/parity/gen_parity_map.py`. To look up from any platform, Ctrl-F
the path you're holding (it appears only in its own column; the row gives the other

A `—` is a legitimate group with no member in that platform (e.g. a Swift↔Python-only test). Only a slug present in exactly one repo is an error.
